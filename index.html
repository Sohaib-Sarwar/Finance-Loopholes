          Important: The combined ROI follows the exact
          structure of the original calculation model. It is
          not a conventional portfolio-weighted ROI unless
          the capital allocation between the Mutual Fund and the Bank
          savings account is explicitly defined. MF return is computed on
          the full entered capital, and Bank return is computed on the
          fixed average bank balance — the two are added, not weighted by
          how capital is actually split between them.
        


        

          Strategy context (conceptual model, not guaranteed):
          This calculator supports evaluating a banking & mutual-fund
          yield strategy that combines money-market fund returns with 24/7
          redemption, strategically maintaining the required balance in a
          savings account around the bank's profit calculation/recording
          time. The same capital can potentially generate returns from both
          the money-market fund and the bank savings account, subject to
          each institution's rules, cut-off times, eligibility and
          transaction settlement. Actual outcomes depend entirely on the
          applicable bank/fund rules, rates, taxes, settlement timing,
          redemption availability and eligibility. This is not financial
          advice and double returns are not guaranteed. See the README for
          full details.
